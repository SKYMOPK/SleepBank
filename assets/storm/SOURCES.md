# Storm cloud texture

NOAA Photo Library, OAR/ERL/National Severe Storms Laboratory, image nssl0041 (1982).
Public-domain U.S. government photograph. Original retained as `cloud-front.jpg`.

Source and licensing:
https://commons.wikimedia.org/wiki/File:Thunderstorm_with_lead_gust_front2_-_NOAA.jpg

The cloud-only crop is desaturated, graded to night, and packaged as a data URI
to support the existing `file://` preview without tainting canvas exports.
